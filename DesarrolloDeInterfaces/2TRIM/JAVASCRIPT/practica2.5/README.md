Solicitud de Cita Médica en el Hospital HM:

Esta aplicación web permite a los usuarios solicitar una cita médica online de forma online.  
Incluye validaciones en tiempo real, creación y eliminación dinámica de citas, y almacenamiento de datos en el navegador con localStorage.

Funcionalidades:
- Formulario interactivo con:
  - Nombre, edad, email
  - Selección de especialidad
  - Turno preferido (con radio)
  - Aceptación de términos (con checkbox)
- Validaciones:
  - Nombre: mínimo 3 caracteres
  - Edad: mínimo 18 años
  - Email válido
  - Especialidad obligatoria
  - Al menos un turno seleccionado
  - Términos obligatorios
    
- Creación dinámica de citas en la página
- Eliminación de citas con un botón
- Guardar y restaurar datos del formulario usando localStorage
- Cambios visuales en campos seleccionados


Estructura del proyecto:
- index.html → Contiene la estructura del formulario y la lista de citas
- styles.css → Estilos de la página, formulario y citas
- script.js → Lógica de validación, creación/eliminación dinámica y almacenamiento en el navegador
- README.md → Este archivo explicativo
